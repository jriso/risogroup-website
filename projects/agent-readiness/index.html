What the BI vendors actually shipped

Hex, Metabase, Omni and Sigma all say they have AI. This reads their documentation instead — every page of it — to work out what each product does today, then uses their changelogs to date when each one said it arrived.

Nothing here asks you to take my word for it. Every cell opens to the vendor's own sentence, the page it came from, and an archived copy of that page from the day it was read.

Where the docs and the changelog disagree

Reading both sources separately means they can contradict each other, and the contradictions are the most interesting cells on the page. A capability in the docs that was never announced is something shipped quietly. One announced that isn't in the docs was renamed, pulled, or narrower than the announcement made it sound.

How this was built

Docs first, changelog second

The earlier version of this analysis was built from changelogs, and it was wrong in a specific way: a changelog tells you what a vendor chose to announce, not what the product does. Capabilities that shipped quietly were invisible, and announcements that never became features counted as shipped.

So the present-day state comes from documentation, and the changelog is laid over the top purely for timing.

Absence has to be proven, not assumed

Saying a vendor lacks something is the easiest claim to get wrong — usually it means "the page I opened didn't mention it". Every doc site here is collected in full and searched, so a doesn't is a statement about the whole corpus.

This caught one of my own errors: Hex's saved agents were marked absent because I enumerated the agent-management section, and Agent Tasks live under explore-data.

Quotes are checked by machine

Every quoted span is compared character-by-character against the live page. This is not paranoia: one quote in an earlier draft turned out to be two separate sentences from the page welded together by a summarising fetch tool. It read perfectly and appeared nowhere.

Doc pages have no history

A changelog entry is dated and stays put. A doc page gets rewritten in place, and the sentence you quoted is simply gone. Every page relied on here is archived, and each cell links to the frozen copy as well as the live one.
